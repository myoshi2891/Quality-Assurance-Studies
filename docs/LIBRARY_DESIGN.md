# ホーム・グローバルメニューの設計

最終更新日: 2026-10-23

## 目的と情報の優先順位

104ガイドを扱う入口として、「初めて学ぶ」「カテゴリから探す」「キーワードで直接探す」の導線を設ける。ダーク背景、ミントの操作色、カテゴリごとの識別色を共有し、本文の説明と余白で情報のまとまりを示す。

ホームの学習マップはカテゴリ名・略号・件数を常時表示する。資格の学習順序と実務カテゴリを分け、バーは全カテゴリ共通の最大件数を基準に表示する。ホバーを前提にせず、タッチでも読める。

## データと拡張

- `lib/navigation.ts` の `NAV_ITEMS` がガイド名・説明・リンク・カテゴリの共通データ。既存カテゴリへのガイド追加は、この配列への登録だけでホーム、マップ、件数、絞り込み、メニュー、検索へ反映される。
- カテゴリ追加時は同ファイルの `NavCategory`、`CATEGORY_ORDER`、`CATEGORY_TITLES`、`CATEGORY_CODES` を更新する。ホームのカテゴリ操作とメニューは登録データから生成され、空カテゴリは表示しない。
- 資格の学習順に追加するカテゴリは `app/page.tsx` の `CERTIFICATION_TRACK` にも登録する。それ以外は実務側に表示される。
- カテゴリの識別色は `app/globals.css` の `data-category` 定義を共有する。カテゴリ追加時は必ず、`app/globals.css` の対応する `[data-category='...']` 定義にレベル色（`--level`）を追加する。この手順を省略してはならない。
- 特定件数に依存する幅・高さを使わず、ガイド一覧は可変列のグリッド、メニューはカテゴリの折りたたみと画面高以内のスクロールで拡張する。

## 検索とナビゲーション

ホームは検索語とカテゴリをANDで絞り込む。カテゴリの件数は全体、結果件数は現在の絞り込みを示す。該当なしからは一操作で検索とカテゴリをリセットする。絞り込み中に学習マップを選んだ場合は絞り込みを解除して、表示されたカテゴリへスクロールする。

メニューはホームへのリンク、検索、結果件数、カテゴリの順に配置する。現在ページのカテゴリを自動展開し、検索中は該当カテゴリを展開する。各ガイドの説明は `aria-describedby` で関連付け、リンク名を維持する。

## レスポンシブとアクセシビリティ

PCではホームのカテゴリ操作を左に固定する。760px以下では横スクロールのカテゴリボタンへ切り替え、検索結果の幅を確保する。メニューは最大620pxの右側パネルで、狭い画面では全幅を使う。

メニューはラベル付きのモーダルとし、開いたら検索へフォーカスを移動する。TabとShift+Tabは可視の操作要素内で循環し、Escape・背景・閉じるボタンで閉じる。通常の閉操作では起点にフォーカスを戻し、ページ遷移時は移動先に委ねる。検索状態は再表示時にリセットする。

ホームのスタイルは `app/index-page.css`、メニューの追加スタイルは `components/header.css` に分け、ページ本文への影響を抑える。動きを減らす設定ではアニメーションとトランジションを停止する。

## TDDと検証

`tests/index/page.test.tsx` と `tests/components/Header.test.tsx` に6件を追加し、未実装状態で失敗を確認してから実装した。カテゴリと検索の組み合わせ、カテゴリの自動生成、空検索の解除、メニューのフォーカス循環、ガイド説明の関連付け、絞り込み中のマップ移動を検証する。対象64件、全体5,653件が成功。lintと変更範囲の型検査も成功。

`bunx playwright test --config playwright.library.config.ts` で320・390・768・1440pxの操作・横あふれ・axeアクセシビリティ検査を行い、12件が成功。既存のlocalhost:3001開発サーバーを再利用し、存在しない場合は開発サーバーを起動する。アニメーションがある要素の検査は完了後に実施する。

全体型検査には既存の無関係なテストファイルのエラーが残るため、変更ファイルを含む型検査の結果と分けて扱う。本番ビルドは今回実施していない。
